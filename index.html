K SKU to P SKU Converter

How to use
  1. Click the box below (or drag and drop) to choose your To Ship order file (.xlsx).
  2. Click Convert now. Each K SKU (set) is replaced by its P SKUs (components), and quantities are multiplied.
  3. Check the result. Green rows were converted successfully. Red rows are K SKUs that are not in the Reference Table and were NOT converted.
  4. Click Download converted file to save the converted Excel file.
  5. To convert another file, click Start over (or refresh the page with F5).
To see which P SKUs make up each K SKU, open the Reference Table tab. Your files stay in your browser and are never uploaded.
